Skills

재사용 가능한 워크플로우/도메인 지식 묶음. 각 스킬은 자체 디렉토리를 가지며 skills/<name>/SKILL.md 형태로 작성합니다. 권장 섹션 구성은 When to Use / How It Works / Examples 입니다.

아직 없음 같은 워크플로우를 두 번 이상 반복하게 되면 그때 skill로 승격합니다. 에이전트/커맨드처럼 한 번 쓰고 끝나는 게 아니라, 여러 상황에서 Claude가 참고할 지식 뭉치일 때 skill이 적합합니다.
