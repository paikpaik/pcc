Hooks

라이프사이클 자동화. hooks/hooks.json을 두면 Claude Code v2.1+가 컨벤션으로 자동 로드합니다. .claude-plugin/plugin.json에 hooks 필드를 명시적으로 추가하면 "Duplicate hooks file detected" 오류가 나므로 절대 추가하지 않습니다.

아직 없음 자동화가 명확히 아쉬운 지점(포맷/타입체크 자동 실행, 세션 요약 등)이 생기면 그때 짧은 단일 스크립트로 추가합니다. ECC는 hooks/hooks.json이 범용 디스패처 프레임워크(scripts/hooks/lifecycle-hook-bootstrap.js 등)를 거치는 구조인데, pcc에서는 그 프레임워크를 통째로 들여오지 않고 필요한 만큼만 직접 구현합니다.
