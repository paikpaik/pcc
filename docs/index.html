pcc 가이드 문서

개인 전용 Claude Code 플러그인. ECC의 agents / skills / commands / hooks / rules 아키텍처 패턴만 참고해서, 실제로 쓰는 만큼만 하나씩 채워가고 있습니다. 카테고리별 상세 내용(각 파일의 한국어 번역 + 원문)은 왼쪽 메뉴에서 해당 페이지로 이동해서 확인하세요.

플러그인 매니페스트. name, version, commands/skills 경로(배열), mcpServers: {} 를 포함.

재사용 가능한 워크플로우/도메인 지식. 자세한 내용은 Skills 페이지 참고.

hooks/ 비어있음

라이프사이클 자동화. 자세한 내용은 Hooks 페이지 참고.

언어별 코딩 스타일/보안/테스트 규칙 (typescript, python). 자세한 내용과 적용 방법은 Rules 페이지 참고.

repo/ECC 참고용

ECC 원본 클론. .gitignore에 등록되어 pcc git 추적 대상이 아님 — 형식/패턴 참고 전용.

디렉토리역할파일 형식
agents/ 특정 작업에 특화된 서브에이전트 (예: 코드 리뷰어, 아키텍트) MD + YAML frontmatter (name, description, tools, model)
skills/ 재사용 가능한 워크플로우/도메인 지식 묶음 skills/<name>/SKILL.md
commands/ 사용자가 직접 호출하는 슬래시 명령어 MD + description: frontmatter
hooks/ 세션 시작/종료, pre/post-tool 등 라이프사이클 자동화 hooks.json (matcher + command)
rules/ 언어별 코딩 스타일/보안/테스트 규칙 (배포용 소스 — 자동 로드 아님, 적용 방법 참고) 언어별 하위 디렉토리 + MD

플러그인 매니페스트 함정

ECC의 PLUGIN_SCHEMA_NOTES.md에서 확인된, 문서화되지 않았지만 실제로 강제되는 검증기 제약입니다.

agents 필드를 plugin.json에 추가하지 말 것 매니페스트 스키마에 없는 필드라 agents: Invalid input 오류로 검증 실패. agents/*.md는 컨벤션으로 자동 인식됨.
hooks 필드를 plugin.json에 추가하지 말 것 hooks/hooks.json은 자동 로드되므로, 명시적으로 선언하면 "Duplicate hooks file detected" 오류 발생.
commands, skills 필드는 항상 배열 값이 하나뿐이어도 문자열이 아니라 배열로 감싸야 함 (["./commands/"]).
version 필드 필수 누락 시 마켓플레이스 설치 또는 CLI 검증 단계에서 실패할 수 있음.

검증 명령어

claude plugin validate .claude-plugin/plugin.json

다음 단계 로드맵

처음부터 다 채우지 않고, 실제로 쓰면서 필요한 것부터 하나씩 추가하는 중입니다.

  1. agent + command 하나로 패턴 검증 — 완료 agents/code-reviewer.md와 commands/code-review.md 작성, claude plugin validate 통과.
  2. rules/typescript, rules/python 기본 규칙 작성 — 완료 coding-style / security / testing 3종 × 2개 언어 작성. 플러그인 루트 rules/는 자동 로드되지 않으므로 .claude/rules/로 복사해야 적용됨 (자세히는 Rules 페이지 참고).
  3. skill 추가 — git-workflow, tdd-workflow 완료 ECC의 팀 규모별 브랜칭 전략/리뷰어용 체크리스트, TDD 강제 커밋 체크포인트·증거 보고서 같은 엔터프라이즈 절차는 빼고, 1인 개발에 실제로 쓸 핵심만 추려서 작성. 다음 후보: react-patterns / backend-patterns / python-patterns 중 하나.
  4. hooks는 자동화가 명확히 필요할 때만 — 다음 후보 세션 요약, 포맷 검사, rules/를 .claude/rules/로 자동 복사하는 설치 스크립트 등 실제로 아쉬웠던 지점이 생기면 추가. ECC처럼 범용 디스패처 프레임워크를 통째로 들여오지 않고, 필요한 만큼만 짧게 구현.
